# Changelog

One line per meaningful change, newest first.

- 2026-09-02 review fixes: practices now group by normalized address (suite folded in from address_2, #/unit/suite treated alike) OR phone within ZIP, so the same office is one row; surnames such as Do/Ma/Ba are no longer emptied by credential stripping; license-number matching only uses dentist (1223) taxonomy licenses; ambiguous nicknames (Pat, Sam, Chris, Alex, Terry, Jerry) and spelling variants removed from config/nicknames.yaml; Dentist License preferred over faculty/resident licenses when propagating to providers.
- 2026-09-02 nppes: providers with an out-of-state primary address but a WA/HI office in practiceLocations are kept using that office; a complete pull flags records NPPES no longer returns (and status D records) is_active = false, never deleting them.
- 2026-09-02 hi_dcca: a run with zero dentist rows across the whole window now fails with a snapshot instead of finishing ok; unrecognized pages are noted and mark the run partial; three unrecognized pages before any hit stop the run; the browser only accepts an unchanged results area when it shows the submitted numbers; run bookkeeping (batch, detail flags) kept out of source_json so config changes do not rewrite rows.
- 2026-09-02 wa_doh: pagination stops with a snapshot if $offset is ignored (repeated page) or max_rows is exceeded.
- 2026-09-02 resolve: `make resolve` re-runs license matching for every source and refreshes data/review/unmatched_<source>.csv; adapter runs snapshot the offending record when normalize or upsert fails (not only HTTP errors); signals uniqueness holds for NULL values (NULLS NOT DISTINCT); test suite now applies the alembic migrations and fails loudly when Postgres is unreachable (INTEGRA_TESTS_ALLOW_NO_DB=1 to skip on purpose).
- 2026-09-02 integration: request/cache counters mean the same thing in every adapter (live requests vs cache hits), `integra pull <unknown>` prints one line instead of a traceback, CLI contract tests, README first-live-run checklist.
- 2026-09-02 resolve: practice resolution by phone + address key (fallback address, phone, solo NPI), org name > existing name > "Dr. Last", Hawaii county from ZIP, orphaned practices deactivated not deleted; license matching (license number in NPPES taxonomies > exact name with state tiebreak > rapidfuzz >= 90 same state), links under 0.8 or ambiguous go to data/review/unmatched_<source>.csv, matched licenses propagated to providers.wa_/hi_ columns.
- 2026-09-02 hi_dcca: MyPVL license-number enumeration adapter (Playwright, one page, 0.5 req/s), file cache under data/raw/hi_dcca/<date>/, Cloudflare/CAPTCHA stop with snapshot and no retry, first results page snapshotted; DOM selectors and synthetic fixtures unverified until the first live run.
- 2026-09-02 wa_doh: Socrata qxh8-f4bd adapter; metadata checked before every pull, $select limited to config business_fields (birthyear never requested, stripped from payload and cache if it ever arrives), all statuses kept with is_active_status, app token header only when SOCRATA_APP_TOKEN is set.
- 2026-09-02 nppes: API-mode adapter for WA and HI, partitioned by ZIP3 prefix and entity type with automatic subdivision past max_skip, both NPI-1 (providers) and NPI-2 (organizations), LOCATION-state and 1223 taxonomy guards in normalize().
- 2026-09-02 Phase 0 scaffold: uv project, Postgres models and migrations, polite HTTP client with disk cache, config YAMLs, fixtures captured from live NPPES and WA DOH.
